## Scope

## Signal Definitions

```python
router_success(pred, gt) = ast_function_name(pred) == ast_function_name(gt)
validator_success(pred, gt) = router_success(pred, gt) and ast_arguments_match(pred, gt)
call_success(pred, gt) = router_success and validator_success
```
